////////////////////////////////////////////////////////////////////////////     T1DIARY     /////////////////////////////////////////////////////////////////////////

Simple android application for meal-logging, taylored for people with type 1 diabetes. 
The application aims to combine food tracking, insulin management, carbohydrate calculations, and personal logging in one convenient interface.

The project is developed primarily for personal use, and as a learning exercise to gain experience in programming development. 



FEATURES
- Food Database
    + Extensive food database: Access nutritional information and carbohydrate counts from existing food databases, alongside a personal database of custom foods.
    + Offline access: Store frequently consumed foods locally for use without an internet connection.
    + Custom foods and recipes: Add new foods and combine multiple ingredients into reusable meals or recipes.

- Insulin Settings
    + I:C ratios: Configure and manage multiple insulin-to-carbohydrate ratios.
    + Basal insulin settings: Store different basal insulin rates and set up automatical switching times.
    + Temporary adjustments: Apply temporary changes to insulin-to-carbohydrate ratios or basal insulin rates.
    + Treatment modes: Switch between insulin pump and pen injection modes.
    + Insulin action duration: Configure the insulin's time of action.

- Carbohydrate Calculator
    + Calculate the total carbohydrate content of meals based on selected foods and quantities.
    + Estimate insulin requirements using the selected I:C ratio.

- Logbook
    + Activity logging: Record meals, insulin doses, exercise, and general notes.
    + Calendar view: Browse previous entries through a calendar interface.
    + Search and filters: Find entries using criteria such as food type, date, and blood glucose level.
    + Blood glucose tracking: Record glucose measurements and associate them with relevant meals or activities.
    + Follow-up logging: Set reminders to record glucose levels after meals or exercise, and link the resulting measurements to their corresponding entries.

- Reminders
    + Set custom reminders at selected intervals after meals, insulin doses, or other activities.
    + Configure automatic or optional reminders for different types of entries.
