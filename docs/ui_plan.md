# Main components:

The application will have 4 main screens:
- Home Screen
- Logbook
- Food Database
- Settings

There will be an upper navigation bar from which the home and settings screens can be accessed.
The home screen will have buttons for the logbook, food database, and settings. 
It will also have an add button in the lower right corner. Pushing it will open up an option bar,
letting you choose "add note" or "add food". 


# Navigation structure

    - home screen
    - logbook
        → calendar
        → add note
        → entry details/edit entry
        → search and filters
    - food database
        → foods list
        → food details/edit food
        → create food
        → search food 
    - settings
        → insulin settings
        → reminder settings
